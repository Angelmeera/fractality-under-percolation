# Figures

The eight figures as they appear in the manuscript, regenerated by the scripts in
`src/` from the files in `results/`, each as a 600-dpi PNG and a vector EPS drawn at
the printed width of 5.0 in (see `src/paper_style.py`). File names predate the paper's numbering; see
`docs/REPRODUCING.md` for which script draws which and the paper figure number.

| file | subject |
|---|---|
| `fig1_pc_dB` | susceptibility and `d_B(p)` through the percolation transition |
| `fig3_alpha_beta_corrected` | `α(p)`, `β(p)` and the mass-law reconstruction under **three** box-mass conventions |
| `fig4_clustering` | clustered `G^A` versus triangle-free `G^B` |
| `fig5_convergence` | closure residual and simulated `p_c` against system size |
| `fig6_dblp` | percolation of the DBLP `w ≥ 60` backbone: `χ(p)`, then `d_B`, γ, δ, α, β of the largest component |
| `fig7_fractality` | the fractality test on fractal networks and controls |
| `fig8_grid_and_size` | box-size grid selection, and the parity effect on the WWW |
| `fig9_fss` | finite-size scaling for the percolation critical exponents |

`fig3` is the one to look at first. The three conventions differ only in what counts as
the mass of a box that percolation has fragmented, and they disagree about *which*
exponent is the fragile one — which is why the paper draws no conclusion on that point.
